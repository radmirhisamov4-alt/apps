# Radmir Apps

Расширяемый каталог приложений для GitHub Pages с отдельными вкладками Windows
и Android, поиском и адаптивными карточками.

- AlgoMotion — визуализатор сортировки и поиска для Windows.
- CryptoSafe — офлайн-сейф для Android.
- Offline Privacy Keyboard — приватная офлайн-клавиатура для Android.

Файлы программ публикуются в GitHub Releases. Кнопки на сайте используют
стабильные ссылки вида `releases/latest/download/...`.

Чтобы добавить новое приложение, достаточно создать ещё одну карточку с
атрибутами `data-product`, `data-platform` и `data-search-text`. Счётчики,
фильтрация и поиск обновляются автоматически.
